# Aldus support

Choose the channel that matches what you need:

- Ask usage, installation, and self-hosting questions in [GitHub Discussions Q&A](https://github.com/Mahcks/Aldus/discussions/categories/q-a).
- Report reproducible app, server, or documentation problems through the [issue chooser](https://github.com/Mahcks/Aldus/issues/new/choose).
- Read the [Aldus documentation](https://aldus.media) for installation, administration, and reading guidance.
- Report vulnerabilities privately through [GitHub security advisories](https://github.com/Mahcks/Aldus/security/advisories/new), following [SECURITY.md](SECURITY.md).

Aldus is public beta software maintained by volunteers. Public support is best effort. Include the Aldus version, platform, what you expected, what happened, and sanitized reproduction details so someone can help efficiently.

Never post passwords, tokens, cookies, private server addresses, personal library data, database files, or copyrighted media.
