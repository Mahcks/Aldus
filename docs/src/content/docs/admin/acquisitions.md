---
title: Automatic requests
description: Connect owner-managed indexers and a download client.
---

Automatic requests are optional. Aldus can read and stream files you already own without Prowlarr or qBittorrent.

1. Open **More → Acquisitions**.
2. Connect Prowlarr and qBittorrent, then test both connections.
3. Configure default destinations and allowed formats for each library.
4. Decide which members may request, bypass approval, or choose a release.

The server owner is responsible for configuring authorized sources and complying with their terms. Aldus does not provide indexers, tracker credentials, or media.
