---
title: Libraries and members
description: Organize access for a household without duplicating media.
---

A library groups books, sources, acquisition policy, and member permissions. It is an access boundary, not a storage folder.

Most households need one shared library. Add another only when its members or media genuinely need different visibility.

Owners manage policy and membership. Editors manage content. Readers consume titles and may request missing formats only when an owner grants that permission.
