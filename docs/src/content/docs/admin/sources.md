---
title: Media sources
description: Add owned ebook and audiobook folders to Aldus.
---

A source points Aldus at a folder it may scan. Client filenames never determine Aldus storage paths.

- **External sources** remain in place and are indexed read-only.
- **Managed sources** receive verified copies finalized by Aldus.

After adding a source, start a scan and review uncertain matches under **Import review**. Aldus skips review only when metadata confidence is sufficient.
