Aldus keeps ebooks, audiobooks, and reading progress on a server you or someone in your household controls.

## If someone invited you

Install Aldus, enter the server address they provided, and sign in. Start with [iPhone and iPad](/read-listen/ios/) or [Android](/read-listen/android/).

## If you run the household server

Start with [Install Aldus](/admin/install/), then add a library and a media source. Readers do not need access to server administration.

## If you are exploring

Open [demo.aldus.media](https://demo.aldus.media), select **Explore demo**, and use the public-domain shelf without creating a permanent account.
