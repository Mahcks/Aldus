---
title: Offline use
description: Keep books available when your Aldus server cannot be reached.
---

Download media while connected to your server. Aldus stores the selected edition and the synchronization data needed to preserve exact progress.

Progress recorded offline is queued on the device. When the server becomes reachable again, Aldus reconciles it against the latest saved revision.

Shared or public devices should remove downloaded media before signing out.
