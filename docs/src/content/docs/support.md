## Reader and device help

Search these docs first for iPhone, Android, offline, KOReader, and connection guidance. If the problem belongs to a household server, contact that server's administrator because the Aldus project cannot inspect private installations.

## Administrators and bug reports

Search [existing GitHub issues](https://github.com/mahcks/aldus/issues) before opening a report. Include the Aldus version, platform, expected result, and exact steps to reproduce.

Remove server addresses, usernames, API keys, filenames, and private library information before posting publicly.

## Security and privacy

Do not report credentials or security vulnerabilities in a public issue. A private contact address will be published here before the public App Store release.
