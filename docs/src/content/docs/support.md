## Reader and device help

Search these docs first for iPhone, Android, offline, KOReader, and connection guidance. If the problem belongs to a household server, contact that server's administrator because the Aldus project cannot inspect private installations.

For help from the Aldus project, email [support@aldus.media](mailto:support@aldus.media). Include:

- Your Aldus version and build number
- Your device model and operating-system version
- What you expected, what happened, and the steps that reproduce it
- A sanitized error message or request ID, if one is shown

Do not send passwords, session tokens, cookies, API keys, pairing codes, complete server URLs, IP addresses, private media, filenames, or private library details.

## Administrators and bug reports

Use [GitHub Issues](https://github.com/mahcks/aldus/issues) for non-sensitive, reproducible bugs and feature requests. Search existing issues before opening one. Readers who do not use GitHub can email [support@aldus.media](mailto:support@aldus.media) instead.

Public reports should contain only sanitized technical details. Contact your hosting provider or system administrator for server, network, certificate, backup, or account recovery issues specific to your installation.

## Privacy requests

Email [privacy@aldus.media](mailto:privacy@aldus.media) for questions about the public demo, support correspondence, or data handled by the Aldus developer. For data on a self-hosted server, contact that server's operator first. See the [privacy policy](/privacy/) for account deletion and retention details.

## Security reports

Email vulnerabilities privately to [security@aldus.media](mailto:security@aldus.media). Do not open a public issue before the problem has been investigated and a fix is available.

Describe the affected Aldus version, impact, and reproduction steps without including real credentials, private media, or data belonging to another person.
